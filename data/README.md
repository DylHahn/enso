\# Data



This folder contains the processed GODAS-derived data products used to reproduce the analyses and figures in the manuscript.



The original data source is the NCEP Global Ocean Data Assimilation System (GODAS). Large raw GODAS downloads are not stored directly in this GitHub repository.



Processed NetCDF and text files needed for the analysis should be placed in this folder. Large processed files will be archived with the Zenodo release of this repository.
